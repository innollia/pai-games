# Codex 작업: 굴러라 신전석 UI 그림 생성 (GPT 이미지)

## 목표
게임 UI(판·버튼·제목판·도장·명패·속도 게이지 틀)를 GPT 이미지 생성으로 그려 PNG로 만든다.
지금 UI는 3D 모델 텍스처를 잘라 붙인 임시 판이다. 이것을 게임 아트와 한 손으로 그린 듯한 진짜 UI 그림으로 바꾼다.

## 그림체 (반드시 맞출 것)
- 게임 3D 모델 텍스처와 같은 그림체: **밝은 구아슈 붓질, 손그림 질감, 따뜻한 크림 사암, 진한 갈색 잉크 외곽선**.
- 참고 그림(먼저 열어 볼 것):
  - `games/speed_tofu/art/boulder/temple.png`
  - `games/speed_tofu/art/boulder/stone.png`
  - `games/speed_tofu/art/boulder/valley.png`
  - `games/speed_tofu/art/boulder/pillar.png`
- 신전 돌을 깎아 만든 물건으로 보여야 한다.
  - **모서리는 둥글지 않게** 비스듬히 깎은 각으로 한다. 사용자가 "UI가 라운드하다"고 싫어했다.
  - 아래쪽은 돌판의 두께가 보이게 조금 더 두껍게 한다.
- 밝게. 어둡거나 칙칙하면 안 된다.
- **글자를 그려 넣지 말 것.** 가운데는 글을 올릴 빈 돌면으로 비워 둔다. 글은 게임이 올린다.
- 배경은 **투명**이다. 생성기가 투명을 못 주면 단색 배경으로 만든 뒤 지워서 알파를 만든다.

## 만들 것 (모두 `games/speed_tofu/art/boulder/ui_gpt/`)

| 파일 | 크기 | 무엇 | 9-slice 여백(대략) |
|---|---|---|---|
| `panel.png` | 512×384 | 큰 카드용 새긴 돌판. 크림 사암, 깎은 모서리, 갈색 잉크 테, 안쪽에 얕게 파인 테두리 한 줄, 아래 두께 | 56 |
| `button.png` | 512×256 | 눌러 볼 만한 도드라진 돌 블록 버튼. 크림, 깎은 모서리, 아래 두께 뚜렷 | 48 |
| `button_down.png` | 512×256 | 같은 버튼이 눌린 모습(아래 두께가 얇고 조금 어두움) | 48 |
| `title.png` | 1024×384 | 제목판: 신전 상인방(lintel) 돌. 양 끝에 작은 기둥머리나 소용돌이 장식, 위아래에 신전 띠 무늬(얇은 파랑·금 띠) | 양끝 160, 위아래 80 |
| `plaque.png` | 768×192 | 구역 이름 명패: 가로로 긴 돌판, 양 끝 장식 | 양끝 96, 위아래 48 |
| `seal.png` | 384×384 | 메달·실패 도장용 팔각 돌 메달. 가운데 빈 원판, 테 장식 | 9-slice 없음 |
| `gauge.png` | 1024×128 | 속도 게이지 틀: 돌에 길게 판 홈. 가운데 홈은 **투명**하게 비운다(속도 막대가 그 안에 보인다) | 양끝 64, 위아래 40 |

- 판·버튼·제목판·명패는 **9-slice로 늘어나도 깨지지 않게** 그린다.
  - 모서리와 장식은 여백 안에만 둔다.
  - 가운데는 늘어나도 괜찮은 고른 돌결로 둔다.
- 색 입히기: 게임은 판·버튼을 modulate로 물들인다(금색 시작 버튼, 빨강 실패 도장). 그래서 **판·버튼·메달은 밝은 크림색(거의 흰 사암)**으로 그린다. 제목판·명패·게이지는 그대로 쓰니 원래 색으로 그려도 된다.

## 마무리
- 모두 합쳐 1.5MB 이하. 필요하면 색 수를 줄이거나 PNG를 최적화한다.
- `games/speed_tofu/submit/boulder/UI_ART.md`에 아래를 적는다.
  - 파일마다 실제 크기
  - 9-slice 여백(left/top/right/bottom 픽셀)
  - 투명 처리 방법
  - 생성에 쓴 프롬프트
- 코드는 고치지 않는다. 게임 연결은 Claude가 한다.
- Godot을 돌리지 않는다. 커밋하지 않는다.
- `games/speed_tofu/` 밖은 건드리지 않는다.
