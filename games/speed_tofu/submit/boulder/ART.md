# ART — 굴러라 신전석 v6

밝은 크림 사암, 코발트, 민트, 황토, 테라코타와 진청록으로 통일한 로우폴리 구아슈 아트. art/boulder/의 9종 GLB와 512×512 PNG를 공유해 길, 신전석, 기둥, 항아리, 수정, 다리를 만든다. 기존 stone/pillar/snow/valley GPT 텍스처는 보존하고 배포본만 축소한다. 생성 경로와 개별 용량은 ART_LOG.md, 정확한 바이트는 ASSET_MANIFEST.json에 기록한다.

| 재질 | 표현과 사용처 |
| --- | --- |
| stone | 코발트 돌, 크림 띠, 황토 흔적. 플레이어·분리 조각·투사체 |
| pillar | 크림 육각 석주, 황토 테두리, 진청록 아래쪽 |
| valley | 크림 석판과 황토 지층. 기존 계곡·수로·광장 |
| snow | 어두운 청록 석판. 흰 빗금 성장 눈과 구별 |
| coast | 조개 석회암·청록 가장자리·테라코타 지층. 해안·조수 정원·바다 신전 |
| crystal | 보라 면, 라벤더 사선, 자주 밑동. 던지기 전용 벽 |
| plank | 황토 나무, 큰 나뭇결, 크림 밧줄. 다리 |
| temple | 테라코타 계단, 크림 기둥, 코발트 띠, 황토 박공. 출발·랜드마크·도착 |
| pot | 테라코타 몸통, 코발트 어깨 띠, 크림 입구. 성장 자원 |

조수 정원은 민트 바탕에 옆 방향 화살표로 물살을 표시한다. 버티면 횡밀림이 줄고 뛰면 벗어난다. 공명 제단은 황금 발판과 가로 압력 막대가 있으며 충전 40%부터 초록으로 바뀐다. 두 구역 모두 눈 성장·수정 던지기·점프와 섞어 새 조작을 응용한다. 빨강은 위험, 보라는 던지기, 흰 빗금은 성장, 노랑은 해빙/발판이며 발판은 압력 막대 형태로 구별한다.

11구역 끝은 넓은 물빛 바다 위 신전이다. 마지막 도약 후 카메라가 해안 신전을 보여 주고 시간·점수·금/은/동·최고 기록을 표시한다. UI는 기존 Pretendard와 오른쪽 조작 버튼, 위쪽 경로/목표 배치를 유지한다. 텍스처는 unshaded와 mipmap으로 읽기 쉽게 렌더링한다. 새 음원 없이 기존 합성음·재사용 파편과 속도선을 사용한다.

재현: build_art.py → 자산별 texture_flow.py 또는 기록된 2D GPT fallback → Blender finalize_art.py → pack_art.py. hwapongstuy UV 도구는 읽기 전용으로 참조한다. 생산 PNG는 전부 512×512, 9쌍의 배포 자산 합계는 4 MB 이하이며 art에는 .gdignore가 없다.
