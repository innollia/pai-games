## 인계 (v26, 2026-10-31) — 새 세션은 여기부터

**v15~v26에서 바뀐 것 (아래 v11 설명보다 이것이 최신)**
- 2구역 아래: 동굴·천장은 없앴다. **열린 지옥 협곡**이다. 떨어질수록 하늘이 검붉게(`_hell_sky`), 밝은 돌길 양옆은 흐르는 용암. 길은 좌우로 굽이치고(`_cave_cx`, 진폭 7.5m·150m 주기), 넓은 굴방 22m/좁은 굴길 11m가 60m마다 번갈아(`_cave_hw`). 길 밖으로 나가면 "치익!"으로 실패. 끝 틈에서 **순풍 길**(`_build_updraft`, 금빛 바람 줄)로 지상 복귀. 수로 받침 기둥은 중간 어둠에서 끝난다.
- 2구역 구멍 건너편 판 옆면 충돌(`_hole_wall`), 길 가장자리는 몸 1/3 걸쳐야 떨어짐(`_edge_tick`).
- 4구역: 착지 자리를 덮는 파란 **지붕 탑**(KIND roof, 30×5×52m) 4곳. 버티기로만 깨진다.
- 흔들다리 전부 삭제(v17 코드 정리). 길 옆 눈금 막대 삭제. 낮은 담(wall)은 옆모습 시점 구역에서만(그 밖은 석상으로 자동 교체, `_thing`).
- 기둥 충돌: 원-원 판정 + 면 반사(`_pillar_hit`), 붉은 깜빡임 없음. 담 윗모서리 스치면 넘겨 줌.
- 멈춤 실패: 땅 가까이 튕기는 중에도 느리면, 또는 2.5초 동안 3m도 못 나아가면(stall) 실패.
- 길을 16m 조각(`_road_chunk`)으로 짓고, 안 고른 갈래는 조각마다 무너짐(`_crumble_tick`). 구역·갈래는 한 프레임에 한 조각씩(`zone_queue`). 같은 모양·재질은 MultiMesh로 묶음(`_batch`) → 그리기 횟수 약 절반.
- 기술 버튼: GPT 팔각 돌 메달(`ui_gpt/seal.png`). 시작 설명 카드 없음(첫 길 안내 "끌어서 조향 / 느려지면 끝"). 단독판 타이틀은 `process_mode`로 게임을 멈춘다.
- 첫 항아리는 길을 가로질러 4개. 6구역 "갈래 눈길", 7구역 "던지고 채우기", 8구역 "좁아지는 방파제" 구간 추가(v23, 실제로 깰 수 있는지 미확인).
- 비밀 창: 화면을 → ← ← ↑ 로 쓸면 구역 11개·숨은 길 6곳 앞으로 가기(`_warp_open`, `_warp_go`).
- 번역: EN 사전 빠진 곳 0개(`scratchpad`의 감사 스크립트 대신 아래 방법). 새 안내 글을 넣으면 EN에 꼭 같이 넣는다. 소스 문자열 안에 실제 줄바꿈을 넣지 말고 `

## 지금 들어 있는 것 (v11)

**코스**

**구역별**

- **4구역 절벽:**
  - 버티기로 착지하는 자리에 탑이 있다.
  - 탑 무리 광장이 있다.
  - 두 단 절벽 아래에 황금 신상이 있다.

**길 고르기**
- **숨은 지름길 7개:** 모두 속도와 이어져 있다. 바람 줄, 끊긴 경계 줄, 버튼 색 봉인, 42m/s 눈금으로 알려 준다.

  - 입구 바닥 화살표가 고를 쪽을 금빛으로 보여 준다.
  - 고르지 않은 갈래는 지운다.
  - 갈림길을 지난 뒤 35m는 길 가장자리가 난간이다.

**화면**
- **타이틀:** GPT가 그린 신전 상인방에 ROCK AND STONE을 새겼다. Play 버튼과 언어 버튼이 있다.

  - GPT가 그린 구아슈 돌 UI다(판, 버튼, 명패, 메달, 게이지 틀).

  - 화면 위에는 큰 속도 숫자와 짧은 바만 둔다.

  - 돌판 도장(의성어)이 찍힌다.
  - 부서진 물건 그림을 입은 조각이 튄다.

  - 효과음은 nkido로 만든 22개다.

## 사용자가 정한 것 (다시 묻지 말 것)

- **언어:** 영어가 기본이다. 한국어는 검수용(`?lang=ko`)이고 글꼴은 Pretendard 그대로다.
- **효과 글:** 흔한 "쾅!·+40" 팝업은 쓰지 않는다. 신전 돌에 새긴 모양처럼 이 게임다운 모양만 쓴다.
- **유물·수집 시스템:** 쓰지 않는다. 숨은 길의 보상은 시간과 속도뿐이다.
- **튜토리얼:** 따로 두지 않는다. 길 위 안내가 맡는다.
- **UI:** 덜어 낸다. 둥근 모서리와 둥근 글꼴은 쓰지 않는다. 기본 도형도 쓰지 않는다.
- **지하:** 보라 배경을 바꿔 끼우는 식으로 하지 않는다. 공간이 이어져야 한다.

## 고친 뒤 올리는 순서

1. `games/speed_tofu`에서 smoke를 한 번 돌린다.
   ```
   "$LOCALAPPDATA/Temp/opencode/godot/Godot_v4.7.2-stable_win64_console.exe" --headless --path . --fixed-fps 60 -s tools/smoke.gd -- boulder
   ```
2. `games/shrine_stone/tools/sync.ps1`을 실행한 뒤 `build.ps1`을 실행한다.
3. boulder·shrine_stone 파일만 commit하고 push한다.
   - main.gd에서는 `GAME_VER["boulder"]` 숫자만 바꾼다.
   - push 명령: `git -c credential.helper= -c 'credential.helper=!gh auth git-credential' push`
