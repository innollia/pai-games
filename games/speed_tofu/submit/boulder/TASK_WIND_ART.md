# Codex 작업: 굴러라 신전석 바람(속도감) 그림 생성 (GPT 이미지)

## 문제
빠를 때 돌 둘레로 지나가는 바람이 지금은 **얇은 흰 상자 줄**이에요. 사용자가 "만화적이라 게임이랑 안 어울린다"고 했어요.
게임 그림체에 맞는 바람·흙먼지 스프라이트로 바꿔요.

## 그림체 (반드시 맞출 것)
- 게임 3D 텍스처와 같은 **밝은 구아슈 붓질, 손그림**으로 그려요.
- 참고 그림:
  - `games/speed_tofu/art/boulder/temple.png`
  - `games/speed_tofu/art/boulder/valley.png`
  - `games/speed_tofu/art/boulder/ui_gpt/panel.png`
- 만화 효과선(얇은 흰 직선, 속도선)은 **쓰지 말아요.**
- 대신 이런 것으로 바람을 그려요.
  - 사막 협곡의 **모래·흙먼지가 붓으로 쓸고 지나간 자국**
  - 반투명한 **따뜻한 크림·황토 바람결**
  - 작은 모래 알갱이 무리

## 만들 것 (모두 `games/speed_tofu/art/boulder/fx_gpt/`, 투명 배경 PNG)

| 파일 | 크기 | 무엇 |
|---|---|---|
| `wind_0.png` ~ `wind_3.png` | 256×64 각각 | 가로로 긴 바람결 한 줄기. 붓으로 한 번 쓸고 지나간 반투명 크림·연황토 자국이에요. 왼쪽 끝은 짙고 오른쪽으로 갈수록 흩어지며 사라져요. 4장은 모양을 조금씩 다르게 해요. 게임은 이것을 돌 뒤로 흐르는 띠로 써요. |
| `dust_0.png` ~ `dust_2.png` | 128×128 각각 | 둥글게 피어오르는 흙먼지 덩이. 구아슈 붓질, 가장자리는 부드럽게 투명해요. 착지·질주 때 바닥에서 피어올라요. |
| `grit.png` | 64×64 | 작은 모래 알갱이 몇 개가 흩어진 모양. 빠를 때 화면 쪽으로 스쳐 가요. |

- 알파는 부드럽게 해요. 가장자리가 딱딱하게 잘리면 안 돼요.
- 전체 불투명도는 낮게 해요(가장 짙은 곳이 alpha 0.7 정도).
- 색은 크림(#efe1c4)부터 연황토(#d9b27a)까지예요. 게임이 modulate로 조금 물들일 수 있어요.
- 글자, 테두리, 배경은 넣지 않아요.
