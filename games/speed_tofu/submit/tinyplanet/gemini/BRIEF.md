# 대사 다시 쓰기 의뢰 (어린 배달부 / The Little Courier)

게임: 작은 행성들을 오가는 배달부 이야기(어린 왕자에서 이름만 따옴, 원작 인용 없음). 주인공 "포스티"는 살아 있는 작은 우체통(왕눈, 국수 다리). 조이스틱으로 행성 둘레를 달려 속도를 모으고, 점프해 진짜 중력으로 다른 별로 날아간다. 주민 다섯의 부탁(풍차 바람 깨우기 → 구식 날다리 받음, 소포를 굴뚝 달로, 유리꽃을 친구 달로 살살, 노을 띠와 같은 빠르기로 달리기 → 유리 덮개, 덮개를 불 별 옆을 스쳐 장미 별로)은 순서 상관없이 할 수 있다(덮개만 형님 부탁 뒤).

입력 파일: `TEXT_KO_base.tsv` (열: key, 언제 나오나, 누가, 한국어, English, 한국어(수정)). 모든 화면 글 164줄.

## 사용자가 직접 고친 것 (그대로 따른다)
1. "스틱으로 달리기 · 막대가 차면 점프!" → 지운다.
2. 주인공 이름표 "나" → "너?" (물음표 포함).
3. "노을 아이" → "형님".
4. "들고 있는 {item}부터 배달하고 다시 와 줘!" → 사용자 반응 "뭐야 이게" (어색함). 말하는 주민 말투로 자연스럽게 다시.
5. "탭하면 닫혀요" → UI에 문장형 금지. "닫기" (또는 탭 유도 표시). 다른 UI 글도 짧은 낱말로.
6. 풍차지기 부탁 → "오, 마침 잘 됐군. 자네 다리가 튼실해 보이는데 나 좀 도와주게나. 바람이 멎어 풍차가 잠들었네. 이 별을 뛰어다녀 바람을 만들어주게나."
7. 풍차지기 감사 → "고마우이, 돛을 받게나. 배달 일이라면 우편의 별, 보라색 별로 가면 되겠군 그래." (돛은 9번처럼 이름이 바뀜)
8. "초록 점선이 보이면 점프하게. 날다 스틱 밀며 뛰면 돛으로 방향을 한 번 튼다네." → "날다가 한번 더 뛰면 조이스틱 방향으로 방향을 튼다네."
9. 돛 → **"구식 날다리"**(날다람쥐를 변형한 낱말). 알림: "구식 날다리! 날 때 '날다리' 버튼을 한 번 누르면 조이스틱 쪽으로 방향을 튼다." 모든 글에서 돛 → 날다리, 스틱 → 조이스틱.
10. "서두르지 말게. 별은 언제나 제자리에서 자네를 기다리니." → "서두르지 않아도 되네. 별은 언제나 제자리에서 릴스를 보고 있으니."

## 장르: 일상개그물 (사용자 지정)
모든 대사는 일상 개그물이다. 무심하고 능청스러운 일상 잡담, 엉뚱한 개그, 주민들끼리 이어지는 반복 개그(예: 별들이 릴스를 본다). 따뜻하고 비꼬지 않음. 조작 안내만은 정확히.

## 이 방식으로 나머지 전부 다시 쓰기
- 주민마다 뚜렷한 말투(풍차지기 = "~하게나/~구먼/자네" 할아버지. 형님 = 느긋한 큰형. 나머지도 정해서 끝까지 지킴).
- 가끔 엉뚱한 요즘 유머("릴스" 같은). 매 줄은 아님. 비꼬지 않음.
- 부탁은 인사·한마디로 시작, 다짜고짜 명령 아님. 조작 안내는 무엇을 언제 누르는지 정확히.
- 폰 말풍선: 한 말풍선 한국어 40자 안팎(넘으면 두 말풍선으로 나눔 표시 " / ").
- UI(버튼·칸·목록): 짧은 낱말, 문장 금지.
- {placeholder}는 그대로 둔다.
- 영어: 바뀐 한국어 뜻과 말투에 맞게 짧고 자연스럽게. 날다리 영어 이름 하나 정해 일관되게.

## 출력
`TEXT_GEMINI.md` 하나만 이 폴더에 쓴다: 표 `key | 누가 | 새 한국어 | English`, 164줄 전부(지우는 줄은 "(지움)"). 맨 위에 주민별 말투 요약 5~7줄. 다른 파일은 절대 고치지 않는다.
