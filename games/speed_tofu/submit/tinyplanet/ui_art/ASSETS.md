# 어린 배달부 UI 그림 목록 (Codex가 그림, Claude가 자르기·배경 빼기·연결)

사용자: "시작화면 AI티 남. ui codex에 hwapong 레포의 범용 규칙 따와서 만들어줘."
방식: hwapongstuy `core/UNIVERSAL_META.md`(범용 메타 v3, ANTI-SLOP 포함) + `STYLE_CARD.md`(이 폴더) + 주제 한 줄 = 메시지 하나. 이 메시지로 영어 프롬프트 한 블록을 먼저 쓰고, 그 프롬프트를 한 글자도 바꾸지 않고 그대로 써서 그림 한 장. 한 장씩.

글자는 그림에 넣지 않는다(ANTI-SLOP). 제목·버튼 글은 게임이 위에 쓴다.
