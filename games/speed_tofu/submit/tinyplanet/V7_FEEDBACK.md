# 어린 배달부 v7 — 사용자 폰 피드백 (2026-10-31 오후)

1. 다른 행성 이동: v6보다 **더** 쉽게.
2. 경로 표시 동그라미(앞길 점선) 크기를 조금만 줄이기.
3. 착지할 때 화면 흔들림은 부드럽게. **하얀색 번쩍임은 제거.**
4. 플레이 도중 글라이더(돛)를 왜 얻었는지, 어떻게 쓰는지 모르겠다.
5. 경로 표시가 "하늘에서 한 번 더 점프하면 어떻게 되는지"를 안 알려 준다. "그러게 초록색일 때 뛰었어야지"가 되면 유저가 허탈하다 → 공중 점프(돛) 했을 때의 길도 미리 보여 줘야 한다.
6. 택배 배달을 해야 한다는 걸 플레이 10분 만에 알았다.
7. 택배를 어디로 배달해야 하는지 까먹었다.
8. 우주로 점프해 버리면 죽을 때까지 허망하게 바라만 봐야 한다.
9. 구체가 아닌 빨간 "행성"(빨간 바위 띠로 보임, 혹은 가시 달린 불 별)은 가까이 가도 중력이 안 끌어당긴다 → 행성처럼 보이는데 안 끌어서 헷갈림.
