# 작은 행성 v5 다듬기 요청 (사용자, 2026-10-31)

1. **시작 화면**: 시작 버튼이 있는 첫 화면(제목 + 큰 시작 버튼, 뒤로 로우폴리 행성들이 천천히 도는 하늘).
2. **튜토리얼**: 풍차의 별에서 단계별로, 해내야 다음으로. 스틱 달리기 → 에너지 막대 → 살짝 점프 → 앞길 점선 색(흰 = 돌아옴, 초록 = 다른 별, 빨강 = 위험) → (돛 받은 뒤) 돛 틀기. 한 번 끝내면 저장, 다음엔 건너뛰기 버튼.
3. **속도감 효과로 재미 높이기.**
4. **디자인 점수 높이기** — 사용자가 준 기준:
   - A. 하나의 디자인 시스템: 주요 색 3~5개 + 강조색 1개, UI 모서리·테두리·그림자 규칙 통일, 캐릭터·배경 선 굵기·명암·질감 통일, 폰트 1~2개. (서로 충돌하는 에셋 스타일은 감점.)
   - B. 움직이는 화면: 버튼 누르면 살짝 줄었다 복귀, 충돌 때 순간 색 변화 + 작은 흔들림, 점수 숫자가 튀어 오르며 사라짐, 성공 때 파티클·빛·화면 전환, 캐릭터 대기 모션과 움직임의 여운.
   - C. 인상적인 장면 하나: 게임 핵심 행동과 연결된 대표 시각 순간(원근이 뒤틀림 / 행동으로 세계 색·구조가 바뀜 / 성공 순간 화면 구성이 극적으로 전환).
   - 제출 전 체크리스트: ① 스크린샷 한 장으로 핵심 요소 구분 ② 캐릭터·배경·UI 스타일 통일 ③ 글씨·버튼이 폰에서 잘 보임 ④ 모든 중요한 조작에 시각 피드백 ⑤ 시작·플레이·게임오버 화면 완성도가 비슷 ⑥ 눈에 띄는 연출 최소 하나 ⑦ 잘림·어긋난 정렬·크기 불일치 없음 ⑧ 처음 보는 사람이 10초 안에 조작과 목표를 앎.
5. **분위기 레퍼런스**(사용자 이미지, 따라 그리지 않고 느낌만): 밝고 채도 있는 툰 3D, 통통하고 둥근 덩어리, 부드럽게 칠한 질감, 파란 하늘에 큰 흰 구름 덩어리, 멀리 갈수록 옅어지는 깊이감. 편지를 문 통통한 배달 새 같은 귀여운 주인공 실루엣.
