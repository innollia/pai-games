## 지금 게임 한눈에 (v35)

**이기는 법**: 우체통에 배달한 짐 수가 이긴다. 끝까지 살아남는 게임이 아니다.
- 코스마다 빨간 우체통이 7~9개 있고, 우체통 하나에는 짐 하나만 들어간다. 먼저 넣는 사람이 차지한다.
- 결승 앞에는 금 우체통이 하나 있다. 짐 1개로 3점이고, 누구나 먼저 넣는 사람이 차지한다.
- 나는 우체통을 가운데 둔 화면 한 폭 안이면 넣을 수 있다(우체통이 화면 오른쪽 끝에 있으면 화면 가운데서도 된다).
  - 범위 안에서는 [짐] 버튼이 초록색으로 바뀌고, 누르면 짐이 우체통까지 날아간다.
- 경쟁자는 우체통 바로 앞에 멈춰 서서 넣고, 55~70%만 성공한다.
- 경쟁자 속도는 동네마다 0.88 → 0.92 → 0.95 → 0.98 → 1.02 → 1.04로 천천히 오른다(v35). 첫 동네는 따라잡기도 반, 배달 성공 하한 35%에서 동네마다 +3%(최대 50%).

**출발**:
- 경쟁자마다 출발 반응(0~0.6초 늦게)과 처음 6초 속도(86~106%)가 판마다 다르다. 넷이 겹쳐 달리지 않는다.
- 빠른 출발: GO 뒤 0.35초 안에 처음 앞으로 밀면 바로 거의 최고 속도("빠른 출발!" 도장). GO 전부터 밀고 있으면 안 된다.
- 맵 위 글자 표지판은 없다(v23).

**짐**:
- 판마다 8개를 받고 시작하며, 최대 10개까지 든다. 머리 위로 한 줄로 쌓인다.
- 짐 하나당 최고 속도 -3%, 점프 -1.75%(연습에서는 무게가 없다).
- 우체통 범위 밖에서 [짐]을 누르면 짐을 뒤로 던지고 대시한다. 대시 속도는 32이고, 다시 던지려면 0.9초 기다려야 한다(버튼에 고리가 돈다).
  - 던진 짐은 길에 떨어져 있어서 상대가 주워 배달할 수 있다.

**빨간 윗길(노란 발판)**:
- 노란 발판은 짐 무게를 40%만 받아 짐 8개로도 6.5m 위 빨간 윗길에 닿는다(PAD_V 24).
- 경쟁자는 대담하면(bold 0.5 이상) 발판을 밟고 윗길로, 아니면 발판을 뛰어넘어 아랫길로 간다.

**화면과 왼쪽 끝**:
- 카메라는 1등을 따라간다. 1등이 빨리 달릴수록 앞이 안 보여 우체통을 지나치기 쉽고, 뒤에 붙은 사람이 그 우체통을 가져간다.
- 화면 폭은 모두가 든 짐의 합으로 정해진다. 양옆 벽이 짐 벽돌(테이프 색 = 주인)로 그려지고, 짐이 줄면 벽돌이 빠지면서 화면이 좁아진다.
- 왼쪽 찢긴 종이 끝에 닿으면 반송된다: 짐 -1, 0.6초 뒤 화면 안쪽으로 다시 들어오고 1.5초 동안은 밀리지 않는다. 빈손이면 짐 1개를 돌려받는다.
- 내가 반송되면 슬로모션 연출이 나온다. 상대가 반송되면 작은 펑만 난다.
- 상대는 한 판에 3번 반송되면 그 판에서 빠진다. 이때 탈락 효과음이 난다. 나도 탈락하면 탈락음이 난다.

**뒤처졌을 때**:
- 선두보다 반 화면 넘게 뒤면 최고 속도가 최대 +25%(따라잡기) 붙는다.
- 화면 두 개 넘게 뒤에서 4초가 지나면 왼쪽 끝으로 다시 들어온다.
- 8초 동안 아무 조작이 없거나 20초 안에 3번 반송되면 "포기할래요?" 버튼이 뜬다.

**나·낮은 문·1등 도착 (v33)**:
- 경주 내내 내 배달부 위에 파란 표시와 "나 · 짐 n"(남은 짐 수)이 뜬다. 화면은 1등을 따라가지만 내가 위아래로 화면 밖에 나가지 않게 맞춘다.
- 낮은 문: 짐 4개 넘게 들고 밀면 0.22초마다 짐 하나가 문에 걸려 뒤에 떨어진다(누구나 주움). 다가갈 때 한 번 크게 안내.
- 결승에 가장 먼저 닿은 사람 +1점(마지막 배달 빼고).

**판 끝**:
- 첫 도착 뒤 3초 "LAST CALL"이 지나면 판이 끝나고, 그 판에 가장 많이 배달한 사람이 이긴다.
- 승부가 정해져도 판은 결승선에서 끝난다. 이때는 도장만 찍고, 마감이 1초로 짧아진다.
- 안전 시간은 120초(코스 길이에 맞춰 늘어남)다.

**컴퓨터 조작(플레이테스트용, v32)**: ←→/A·D 달리기, ↑/W/Space/Z 점프, ↓/S/Shift/X [짐](배달·던지기), Enter/Space 시작·카드. 터치 화면이 아니면 제목 아래에 안내가 뜬다.

**흐름**:
- 타이틀 뒤에서는 넷이 알아서 첫 코스 풍경의 2.5km 길을 끝없이 경주한다(나도 AI, 화면 반폭 6.5로 가까이, 경기 소리·도장 없음, 결승이 보이지 않음).
- 타이틀 → 연습(처음 한 번: 달리기·점프·배달·던지기·왼쪽 끝) → 모드 카드 → READY/SET/DELIVER 도장 → 경주.
- 경주 → 특전 또는 길 카드 → 6동네(각 2판 승) → 마지막 배달 → 영수증 결과(도장·한 줄 기록·메달 6개) → 별점.

**모드**:
- 기본
- 밤 등불: 우체통은 선두의 빛 안에서만 보인다.
- 과속: 짐 4개 이하면 천장 가속과 벽 반동이 켜지고, 대시가 40으로 빨라진다.

**메달**: 금 = 2판 안에 이기고 그 코스에서 6개 배달. 은 = 3판 안에 이김. 동 = 완주. 기록은 `user://screenrace_v12.cfg`에 저장된다.
