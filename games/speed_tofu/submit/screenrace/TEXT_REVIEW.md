# 화면 밖 경주 — 게임 글자 검수표

게임에 나오는 글 150개예요. 영어는 모두 한글 뜻 그대로 옮겼어요. **"영어 뜻(한글로)"** 칸은 영어를 다시 한글로 옮긴 것이라, 한글 칸과 뜻이 같은지 보시면 돼요.

고칠 줄은 번호와 고친 한글만 보내 주세요. 예: `12: 짐을 우체통에 넣어!` 영어는 제가 맞춰 고쳐요.

- `%d` 자리에는 숫자, `%s` 자리에는 이름·글이 들어가요.
- `/` 는 줄바꿈이에요.
