# 화면 밖 경주 — 노는 내용 (v18, 2026-10-31)

규칙 숫자를 한눈에 보려면 `README.md`를, 바뀐 이유는 `DECISIONS.md`를 본다.

## 핵심 결정: 앞설까, 뒤에 붙어 배달할까
- 배달한 짐 수로 이긴다. 1등은 카메라가 따라와서 빠를수록 앞이 안 보이고 우체통을 지나친다. 뒤에 붙은 사람은 우체통을 보고 가져간다.
- 짐은 점수의 재료이면서 무게다. 많이 들면 느리다.
- 짐을 던지면 대시하지만, 배달할 짐 하나를 버리는 것이고 던진 짐은 상대가 주울 수 있다.
- 화면 폭은 모두가 든 짐의 합이다. 배달이 늘수록 화면이 좁아져서 끝으로 갈수록 빡빡해진다.

## 구간 — "짐을 들까 버릴까"의 답을 뒤집는다
| 구간 | 규칙 | 노는 방식 |
| --- | --- | --- |
| 경사로 | 걸어 오르면 기울기·짐만큼 느려짐, 뛰어넘으면 속도 유지 | 막혀서 멈추는 곳이 없다. 점프 타이밍의 문제 |
| 저울 | 짐 6개 이상으로 밟으면 튕겨 위 지름길 | 무거움이 표가 된다 |
| 상승풍 | 짐 4개 이하면 위로 뜬다 | 저울과 답이 반대라 언제 버릴지 미리 정한다 |
| 차단문 | 선두가 닿으면 잠깐 닫힘 | 1등이 손해. 일부러 2등으로 붙는다 |
| 낙하마루·흔들다리 | 무거우면 뚫리거나 무너짐(무게 6) | 무거운 사람만 아래 빠른 길로 간다 |
| 낮은 문(길 고르기) | 짐 4개 이하만 통과 | 문 앞에서 짐을 줄일지 돌아갈지 고른다 |
| 얼음 내리막 · 맞바람(길 고르기) | 못 멈춤, 무거울수록 빠름 / 뒤에 붙으면 바람 없음 | |

- 새 구간은 처음 나올 때 길 위 표지판에 한 줄로 설명하고, 배운 직후 예전 구간과 섞인 응용 구간이 나온다.
- 동네 6곳: 시장, 강변(흐르는 바닥), 건널목(기차), 야시장(정전), 흔들다리, 지붕. 마지막은 "마지막 배달" 한 판이다.

## 모드 3개
- **기본**
- **밤 등불**: 선두가 유일한 빛을 들고 있고, 우체통은 빛 안에서만 보인다. 빠르면 빛이 흔들린다.
- **과속**: 짐 4개 이하면 천장에 부딪혀 가속하고 벽에서 튕긴다. 가벼움이 곧 힘이다.

## 처음 30초 — 직접 해 보는 연습(처음 한 번, 타이틀의 ?로 다시)
1. 스틱을 오른쪽으로 → 달리기
2. [점프]로 상자 넘기
3. 우체통이 화면에 보이면 [짐]이 초록 → 탭해서 배달. 이 단계는 실제로 배달해야 넘어간다. 지나치면 우체통이 앞으로 옮겨진다.
4. 다른 곳에서 [짐]을 누르면 던지고 대시
5. 찢긴 왼쪽 끝이 다가와 짐 하나를 먹는다 → "가장 많이 배달하면 이긴다"
- 연습에서는 짐 무게가 없다. 막힌 단계는 15초 뒤 넘겨 준다(배달 단계는 빼고).

## 끝
- 판 끝: 첫 도착 → 3초 LAST CALL → 그 판 배달이 가장 많은 사람이 이긴다. 판은 늘 결승선에서 끝난다.
- 판 사이: 이기면 특전 카드 2장(신발·끈·용수철·바람·가벼운 상자·단단한 몸), 지면 다음 길 카드 2장(낮은 문·얼음·맞바람).
- 결과 영수증: 순위 도장(DELIVERED / RETURNED), 배달 수·시간 한 줄, 코스 메달 6개, 다시 하기 버튼.

## 다시 할 이유
- 코스 메달: 금 = 2판 안에 이기고 그 코스에서 6개 배달, 은 = 3판 안, 동 = 완주.
- 모드별 최다 배달 기록이 폰에 저장된다.
- 모드 3개는 같은 코스라도 답이 다르다(밤 등불은 따라가야 보이고, 과속은 가벼워야 강하다).
