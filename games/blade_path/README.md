# 일격의 길 (단독판)

speed_tofu 의 합격작 "★ 일격의 길"(blade)을 떼어 낸 독립 Godot 4.7.2 프로젝트. 파이 요청(10/30)으로 반복 성장 구조를 넣었다.
플레이: `https://innollia.github.io/pai-games/games/blade_path/web/`

- 켜면 튜토리얼: 막기 → 베기 → 간파 → 간파 뒤 베기. 단계마다 맞는 쪽으로 밀 때까지 멈춘다. "건너뛰기 >" 로 넘길 수 있다.
- 검객 순서(10/30 두 번째 요청): 찌르기 → 속임수 → 베기(같은 쪽 두 번, 상자 두 겹) → 거합(무작위로 서 있다가 눈이 번쩍한 뒤 순식간에 뽑음) 두 바퀴, 9번째부터 끝판왕 검귀(체력 9999, 안 죽음, 넷을 섞어 씀, 벤 횟수 5번마다 단이 오름, 준 피해를 기록). n번째(0부터): 체력 6+4n, 공격 2+n, 예비 시간 ×max(0.55, 1-0.05n). 이기면 능력 고르기(체력 자동 회복 없음, 10/31).
- 조작(10/30 세 번째 요청): 화면을 밀면 칼 방향(←→↑↓)만 정하고, 아래 [막기]·[베기] 버튼으로 행동한다(두 손가락 동시). PC는 방향키/WASD + J 막기 · K 베기. 칼 없을 때 막기 = 헛막기(0.35초 굳음, 피해 없음).
- 공격 표시: 빨간 상자 없앰. 적 칼이 그쪽으로 들어 올려지고(좌우 = 세운 칼, 위아래 = 눕힌 칼) 흐린 잔상 셋이 지나갈 길을 보여 준다. 칼은 버티다 끝에 몰아쳐 온다. 베기 검객의 두 번째 칼 = 잔상 칼 한 자루 더. 빈틈만 검은 테두리 초록 상자.
- 간파하면 연속기 중간이라도 끊기고 초록 상자가 떠서 내가 직접 벤다(간파 반격 업그레이드는 없앴다).
- 헛공격(쉬는 중 휘두름, 빈틈에 엉뚱한 쪽, 거합 번쩍 전): 체력 -1, 0.55초 굳음(칼 처짐), 바닥 빨강, 상대가 바로 친다.
- (10/31에 돈·상점·업그레이드 없앰. 아래 마지막 줄 참고)
- 기록·도감·설정은 `user://blade_path.json` 에 저장.
- `g/blade.gd`: 게임 전부. `tofu.gd`: 공용 틀(shrine_stone 과 같은 파일). 웹 빌드: `powershell -ExecutionPolicy Bypass -File tools\build.ps1` → `web\`
- 조작(10/30 네 번째 요청): [막기]·[베기] 버튼을 누른 채 밀면 민 쪽으로 방향을 잡고 그 자리에서 발동(38px). 안 밀고 떼거나 0.14초 누르고 있으면 잡아 둔 방향으로 발동. 화면 빈 곳 밀기로 방향만 잡는 것도 남김. 1인칭 내 칼은 숨김(눈앞 칼이 닿기 전에 막은 것처럼 보여 막기를 안 누르게 됐다). `tofu.gd` 에 `_btn_down/_btn_drag/_btn_up` 훅 추가.
- 설정화 모양(10/30 다섯 번째 요청, 시험 적용): `g/look.gd` 한 파일에 모았다. 찌르기 = 주황 삿갓·주황 망토·청록 옷, 속임수 = 검은 챙 모자·붉은 목도리 끈, 베기 = 쇠 투구·털 목깃·갈색 망토, 거합 = 옅은 삿갓·흰 겉옷·붉은 목도리, 바탕 누런 종이색. 끝판왕은 그대로. **되돌리기**: `g/look.gd` 의 `ON := true` → `false` 후 빌드(또는 이 커밋 하나를 revert).
- 로비(10/30 여섯 번째 요청, 클래시 로열식 홈 화면): 쓰러지면 상점 대신 로비로 간다. 위 = 돈·최고 기록 띠, 아래 = 탭 줄 [업그레이드 | 전투 | 캐릭터 | 도감]. 전투 탭 = 큰 노란 [전투] 버튼 + 지난 판 결과 + 뒤에 마지막에 진 검객이 서 있음 + "튜토리얼 다시 보기". 업그레이드 탭 = 예전 상점(살 수 있으면 탭에 빨간 ! 표시). 캐릭터 탭 = 내 능력치와 기록(싸운 판·막기·간파). 도감 탭 = 검객 5종 칩, 고르면 그 검객이 3D로 서 있고 설명·만남·쓰러뜨림 수(못 만났으면 ??? 검은 그림자). 튜토리얼은 처음 한 번만(저장 `tut`).
- 10/30 일곱 번째 요청: 설정화 모양 안 어울려서 끔(`g/look.gd` `ON := false`, 파일은 남김). 간파로 연 빈틈에서 엉뚱한 쪽으로 베면 피해 없이 "간파 놓침"(느려짐 끝, 다음 공격으로). 칼을 막으면 폰 진동 45ms, 간파는 160ms 세게(`Input.vibrate_handheld`, 안드로이드 브라우저만, 아이폰 사파리는 진동 안 됨).
- 10/30 여덟 번째 요청: 막은 순간 칼 자리에 불꽃(보통 14개, 간파 26개)과 화면 멈춤(보통 0.05초, 간파 0.09초) + 살짝 흔들림. 버튼 누름 애니메이션: [막기]·[베기]는 눌리면 쑥 들어가고 흰 고리가 퍼지고 떼면 튀어 오름(`tofu.gd` `_kit_draw`), 로비 탭·업그레이드 줄·도감 칩·[전투]는 줄었다 튀어 오름(`_press`, [전투]는 애니메이션 끝나고 출발). 공격 모양을 검객 성향대로(`sty`, `_bpos`/`_brot`): 찌르기 = 칼끝을 겨누고 곧게 찌름, 속임수 = 칼끝을 흔들다 휘두름, 베기 = 크게 젖혀 둥글게 벰, 거합 = 칼집에서 뽑아 그음, 끝판왕 = 수마다 넷 중 하나. 잔상 길도 같은 모양을 따른다.
- 10/30 아홉 번째 요청: 베기 검객 두 번째 칼이 첫 칼을 간파하면 끊겨 안 오던 것 고침(두 번째 칼은 간파해도 반드시 옴, 칼을 바로 다시 젖혀 들고 최소 0.4초). 로비 위 띠 오른쪽 [설정] → 소리 크기·진동 세기 0~10(`vol`/`vib` 저장, 소리 = 버스 0 볼륨, 진동 = `_buzz`). 싸울 때 상대 이름·설명 글 뺌("n번째 상대"만), 이름은 로비 도감에서만.
- 10/30 열 번째 요청: 파이가 보낸 효과음 9개를 `sfx/` 에 넣음(앞뒤 무음 잘라 냄). 내 베기 적중 = `hit`, 간파 빈틈에 엉뚱한 쪽(간파 놓침) = `miss`, 헛공격 = `whiff`, 그냥 막기 = 이번 칼 모양(`sty`)대로 `block_thrust/trick/slash/iai`(끝판왕도 수마다 그 모양 소리), 간파 = `parry`, 쓰러짐 = `death`. 맞음·로비 버튼 등 나머지는 예전 삑 소리. `blade.gd` `sfx()` / `SND` / `BLOCK_SND`.
- 10/30 열한 번째 요청: 헛공격·공격 실패 소리가 안 들린다 → 효과음 전용 플레이어 4개(`sfx_p`)로 삑 소리와 분리, 베기를 눌렀는데 안 들어가는 모든 경우에 소리: 쉬는 중·칼 오는 중 = `whiff`(벌 있음), 빈틈에 엉뚱한 쪽 = `miss`(공격 실패, 간파 빈틈이면 벌 없음), 굳은 중·맞은 직후·벤 직후·전투 밖 = `whiff`(벌 없음). 연격(`link`): 2단부터(끝판왕은 늘) 연속기의 다음 칼(베기 두 번째 칼·거합 제외)이 주황 칼 + 주황 잔상으로 미리 들려 있다. 그냥 막으면 주황 칼이 바로 들어옴(예비 시간 ×0.7, 최소 0.32초), 간파하면 연격까지 다 끊기고 빈틈. 간파 넓게 업그레이드 너프: 단계당 +0.04 → +0.015초(최대 0.40 → 0.275초), 값 6 → 10냥씩.
- 10/31 요청(보스 전투에 키우기 느낌이 안 어울림): 돈·상점·업그레이드 탭을 없앴다. 매 판 맨몸(체력 6, 베기 힘 1, 간파 0.20초)으로 시작. 검객을 쓰러뜨리면 체력 회복 없이 능력 카드 셋 중 하나를 고른다(`PERKS`, 이번 판에만): 단단한 몸(최대 체력 +4), 날 선 칼(베기 힘 +1), 맑은 눈(간파 +0.02초, 4번까지), 상처 동여매기(체력 절반 회복, 체력이 꽉 차면 안 나옴), 숨 고르기(간파마다 체력 +1, 3번까지), 흔들림 없는 손(헛공격 체력 안 깎임, 1번), 긴 빈틈(초록 빈틈 +30%, 3번까지). 카드가 뜨고 0.45초는 눌리지 않는다(베기 연타 오작동 방지). 로비 탭은 [전투 | 캐릭터 | 도감] 셋. 지난 판 결과에 고른 능력을 적는다. 큰 숫자 = 쓰러뜨린 수.
- 10/31 두 번째 요청: 간파로 연 빈틈(`gp`)에 벤 칼은 피해 두 배(`_cut`, "간파 일격! x2"). 파이가 지정하지 않은 삑 소리(맞음·로비 버튼·승리·간파 직전 등 `beep`/`play`)를 전부 끔: `blade.gd` 에서 `beep()` 를 빈 함수로 덮어씀. 이제 소리는 `sfx/` 9개뿐.
- 10/31 세 번째 요청: 적 패턴(박자·칼 수·속임수·같은 쪽 두 번·연격)은 그대로 두고 **방향만** 연속기마다 무작위로 섞음(`dmap`, 연속기 첫 칼에서 4방향 순열을 섞어 그 연속기 전체에 씌운다. 튜토리얼은 고정). 빈틈은 원래대로 마지막 칼이 온 쪽(`rdir`)의 반대(`OPP`)로 고정.
- 10/31 네 번째 요청: 파이가 보낸 거합 소리 둘(`sfx/iai_draw1`·`iai_draw2`, 앞뒤 무음 잘라 냄)을 순서대로: 눈이 번쩍할 때 `iai1`, 칼이 칼집에서 빠져나와 보일 때 `iai2`. 속임수 칼끝 흔들림은 방향이 바뀌는 진짜 속임수 칼(`feinting`)에만, 세기 0.22 → 0.08.
- 10/31 다섯 번째 요청: 연격 사이에 텀(`fs = 5`, `_link_beat`): 그냥 막으면 다음 칼이 그 자리에 들린 채 `beat`(0.42×예비 배율, 최소 0.26초) 동안 서 있다가, 앞 절반 흰 칼 → 뒤 절반 주황 칼로 바뀌며 살짝 더 젖힌 뒤 들어온다. 텀 동안 막기를 누르면 헛막기. 간파 판정 기본 0.20 → 0.15초, "맑은 눈" 단계당 +0.02 → +0.04초(4번 다 고르면 0.31초).
